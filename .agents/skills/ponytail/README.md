# ponytail

Vendored from https://github.com/DietrichGebert/ponytail (MIT license), v4.10.0, 2026-09-28.

The laziest solution that actually works: question whether the code needs to exist, stdlib before
custom code, native features before dependencies, one line before fifty. Three intensity levels
(`lite`, `full` — default, `ultra`).

| File | Consumed by |
|---|---|
| [`SKILL.md`](SKILL.md) | Claude Code Agent Skills (`Skill` tool / `~/.claude/skills`); plain markdown for any other tool |

Pairs with [`../karpathy-guidelines/`](../karpathy-guidelines/): karpathy says think before coding and
keep the diff surgical, ponytail says how short the result should be.
