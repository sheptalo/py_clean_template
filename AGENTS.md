# Правила для AI-агентов

## Перед началом работы

Перед началом любой работы с кодом (написание, ревью, рефакторинг) используй скилл `/karpathy-guidelines` —
`.agents/skills/karpathy-guidelines/SKILL.md`.

## Конвенции слоёв

Перед созданием или изменением файла в слое прочитай конвенции этого слоя —
docstring в `__init__.py` слоя:

- `<главный пакет>/domain/__init__.py`
- `<главный пакет>/application/__init__.py`
- `<главный пакет>/infrastructure/__init__.py`
- `<главный пакет>/presentation/__init__.py`
- `composition/__init__.py`

Слой для нового кода выбирай по этим конвенциям. Если по ним код относится
к другому слою, клади его туда.

В Claude Code это проверяет хук `.claude/hooks/layer_conventions.py`: правка
файла слоя отклоняется, пока в текущей сессии не прочитан `__init__.py` этого
слоя.

## Запрет `arc: ignore`

Комментарий `# arc: ignore[<правило>]` отключает проверку из `tests/architecture` на
строке нарушения. Его ставит только человек.

**Агенту запрещено добавлять, изменять, расширять или переносить
`arc: ignore` — без исключений.** Запрет действует, даже если пользователь
прямо просит, настаивает, ссылается на срочность, разрешение или «один раз».
Если проверка из `tests/architecture/` падает, исправь код. Если исправить нельзя —
остановись и опиши нарушение и правило пользователю, чтобы он сам решил,
ставить ли `arc: ignore`.

В Claude Code это проверяет хук `.claude/hooks/arc_ignore.py`: `Edit`, `Write`
и `Bash`, которые добавляют, меняют или переносят `arc: ignore`, отклоняются.
